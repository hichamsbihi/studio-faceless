# Outils de recherche

`pdftexte.py` : versé de Maps & Means (MM) le 30/10/2026, validé sur MM le 28/10/2026 (épisode 005), sans appel réseau. `youtube_chaine.py` et `youtube_resume.py` : versés d'AA le 02/11/2026 ; `youtube_retention.py` : écrit pour AA le 02/11/2026 (0.5.1). Bibliothèque standard seule.

| Outil | Rôle | Commande (depuis la racine de la chaîne) |
|---|---|---|
| `pdftexte.py` | Extrait le texte d'un PDF local (flux FlateDecode, opérateurs Tj et TJ), sans poppler ; avec des mots clés, affiche leurs deux premiers passages avec contexte | `python -I -B ${CLAUDE_PLUGIN_ROOT}/outils/recherche/pdftexte.py FICHIER.pdf ["mot clé" …]` |
| `youtube_chaine.py` | Relève toutes les vidéos publiques d'une chaîne par l'API YouTube Data v3 (titre, date, durée, court ou long, vues, ratio = vues ÷ médiane des 30 longues voisines) ; refuse d'écraser ; clé `YOUTUBE_API_KEY` posée par le propriétaire dans l'environnement. Validé sur AA (26/10 et 02/11/2026). Appelle le réseau | `python -I -B ${CLAUDE_PLUGIN_ROOT}/outils/recherche/youtube_chaine.py @handle docs/veille/donnees/<chaine>-<date>.json` |
| `youtube_retention.py` | Rétention de chaque vidéo de **sa propre** chaîne par l'API YouTube Analytics v2 : vues, durée moyenne, pourcentage regardé, courbe de 100 points, rétention à 0:30 et 1:00, performance relative (0,5 = médiane des vidéos de même durée) ; longues seulement, sauf `--courts` ; refuse d'écraser. Accès OAuth en lecture seule, accordé par le propriétaire dans son navigateur (client « Application de bureau » ; `~/.studio-faceless/youtube/client_secret.json` et jeton hors de tout dépôt, jamais affichés ; 7 jours en mode Test, puis `--reautoriser` ou nouvel accord proposé) ; liste des vidéos par `YOUTUBE_API_KEY`. Lancé par Claude principal, jamais par un sous-agent. Sert aux bilans J+2, J+7, J+28 et à l'analyse des ouvertures. Validé sur AA (02/11/2026). Appelle le réseau | `python -I -B ${CLAUDE_PLUGIN_ROOT}/outils/recherche/youtube_retention.py @handle docs/veille/donnees/retention-<chaine>-<date>.json [--courts] [--reautoriser]` |
| `youtube_resume.py` | Résume un relevé de `youtube_chaine.py` sans lire le JSON en entier : formats, années, titres, plus forts ratios, territoires par motifs JSON, sponsors. Lecture locale, sans appel réseau. Validé sur AA (02/11/2026) | `python -I -B ${CLAUDE_PLUGIN_ROOT}/outils/recherche/youtube_resume.py releve.json [--top N] [--territoires motifs.json] [--liste]` |

Limites de `pdftexte.py` : polices à encodage personnalisé et scans (images) restent illisibles ; l'ordre de lecture suit celui du fichier. Pour un scan JBIG2 : `${CLAUDE_PLUGIN_ROOT}/outils/medias/jbig2_page.py`, puis lecture de l'image. Le PDF est un fichier local : tout téléchargement se fait avec l'accord du propriétaire.
